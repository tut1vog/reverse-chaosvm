## Verdict

**Module 76 and `slide-jy.js` are different libraries.**

- `slide-jy.js` is jQuery 1.11.3 (96,410 bytes). Evidence: explicit
  `"1.11.3"` version literal; `noConflict` global-export footer;
  ~47 `extend` occurrences (jQuery spreads `$.extend` liberally); no
  `Zepto` / `ajaxJSONP` tokens.
- Module 76 is Zepto (27,825 bytes, embedded as a webpack module).
  Evidence: explicit `Zepto` literal; exports `ajaxJSONP` (a Zepto-only
  ajax method — jQuery 1.x uses `jsonp` via `$.ajax({dataType:"jsonp"})`
  instead); no `jQuery.fn.init` / `Sizzle` / `noConflict`; only ~3
  `extend` occurrences, consistent with Zepto's slimmer surface.

The two files therefore play the same role (`window.$`) but are
alternatives, not the same library. Module 64 picks between them at
load time: on mobile user-agents it does `window.$ = n(76)` (inline
Zepto); otherwise it fetches `/slide-jy.js` via `getScript` and waits
for `window.$` to be assigned by that script (jQuery).
