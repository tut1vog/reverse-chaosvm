## Phase 32 planning: Switch cache key to source hash

**Outcome**: plan created

**What was done**: User identified that TDC_NAME is unreliable as cache key — same TDC_NAME can map to different XTEA params (confirmed in 28.13/28.14). New approach: strip eks from tdc.js source, compute SHA-256 hash, use as cache key. This ensures builds with identical code share entries regardless of per-session eks variation.
